# ExamAI - Система комп’ютерного зору з використанням Django та PyTorch

## Опис проєкту
**ExamAI** - це веб-додаток, який поєднує сучасні технології **комп’ютерного зору**, **глибокого навчання** та **веб-розробки**.  
Проєкт дозволяє обробляти відео з вашої веб-камери в реальному часі, виявляючи та розпізнаючи об’єкти безпосередньо у браузері.

## Основні можливості
- Робота з веб-камерою прямо у браузері  
- Обробка кадрів у реальному часі за допомогою моделі YOLO  
- Розпізнавання кількох об’єктів одночасно  
- Відображення результатів із підписами об’єктів  
- Вибір конкретної камери, якщо їх декілька  
- Використання GPU для пришвидшення обчислень (якщо доступно)  
- Простий та зрозумілий інтерфейс  

## Технології
- **Backend:** Django (Python)  
- **Frontend:** HTML, CSS, JavaScript  
- **ML Framework:** PyTorch  
- **Model:** YOLOv5 (через `torch.hub.load`)  
- **Інші бібліотеки:** OpenCV, NumPy, torchvision
